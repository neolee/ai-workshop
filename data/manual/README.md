# 手工下载投递区

自动抓取失败时（主要预期在中国三市），把官方文件下载到这里，由同一套 parser 解析。

## 目录约定

```
data/manual/<source_id>/<原始文件名>
```

| 城市 | source_id 示例 | 期望文件 |
|---|---|---|
| 北京 | `CN-BJ-GB-2025` | 2025 年统计公报 HTML/PDF |
| 北京 | `CN-BJ-YB-2001` | 2001 年统计年鉴「综合核算」章节 |
| 上海 | `CN-SH-GB-2025` | 2025 年统计公报 |
| 深圳 | `CN-SZ-GB-2025` | 2025 年统计公报 |
| 深圳 | `CN-SZ-YB-2024` | 2024 年统计年鉴 |

命名规则与 `data/raw` 一致：`组织-数据集-版本`。

## 规则

1. 文件保持原始格式与文件名，不要手工改表、不要裁剪。
2. 抓取时间与来源 URL 由 `ingest` 时通过命令行或 `manifest.json` 补录。
3. 手工来源在 `source` 表中的 `acquisition` 字段记为 `manual`。
4. 同一 `source_id` 只放一个版本；官方发布新版请新建目录。
