## 4. 与计划的偏差

1. **uv 缓存位置**：本机沙箱不允许写 `~/.cache/uv`，改用 `UV_CACHE_DIR=$PWD/.uv-cache`。该目录已加入 `.gitignore`；你本地正常执行 `uv sync` / `uv run` 不需要这个变量。
2. **pandas 版本**：解析到 3.0.6（非 2.x）。S1 未使用 pandas，接口无影响；S2 起如遇 API 差异再处理。
3. **新增 `.gitignore` 条目**：`data/db/*.sqlite`、`.uv-cache/`、`.pytest_cache/`。

## 5. 需要你确认

1. **`config/cities.yaml` 口径**：8 城的边界、人口口径、面积口径描述是否与你的理解一致（尤其深圳的 `breaks` 记录方式、香港「中国分母」备注）。
2. **锚点初值**：`config/anchors.yaml` 现有 6 条，值是 S2–S5 要核对的官方数；若你手头有更权威的版本可先替换。
3. **`data/db` 不入库**：数据库可由 `data/raw` 重建，已加入 `.gitignore`。若你希望入库留存，我可以撤掉该条。
