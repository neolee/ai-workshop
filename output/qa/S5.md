## 5. 实施中的发现

1. **上海年鉴是 iframe 结构**：索引页 → 年份页 → `tjnj{YYYY}.htm` 目录 → 表页 `C03/C0301B.htm`（数据帧）。数据帧是标准 HTML 表格，表 3.1 一次覆盖 1978–2024。
2. **北京年鉴的表格在页面上是 JPG，但同目录下有 `.xls`**：`html/C0201.jpg` 是展示图，`html/C0201.xls` 才是数据。这是本次最关键的发现——否则会误判为「只能 OCR」。
3. **`C0201.xls` 是 BIFF 格式**（OLE2、代码页 936），`openpyxl` 读不了，需 `xlrd`。
4. **国家统计局「国家数据」API 对本机 403**（WAF 拦截），不能作为备选源。
5. **深圳年鉴 PDF 有文本层**（395 页），`pypdf` 可抽取；抓取阶段就把全文落盘为 `shenzhen.txt`，ingest 不重复解析 PDF。
6. **公报正则要留脚注位**：北京写作「年末全市常住人口[4]2180.0万人」，中间夹脚注标记。
7. **深圳面积随深汕口径跳变**：2023 年及以前 1,997.47 km²，2024 年起 2,465.77 km²，由适配器逐年写入并加注。

## 6. 需要你确认

1. **深圳 2024 年起是否含深汕**：官方全市 GDP 36,801.87 亿元的核算范围是否已包含该区。目前按 INIT 的说明「2024 年后纳入」处理，面积同步跳到 2,465.77 km²。若官方未含而面积已含，需要回退面积或调整 GDP。
2. **人口存的是年末常住人口**，年平均由 S6 的 build 计算 `(上年末+本年末)/2`；这样保留原始观测值，是否认可。
