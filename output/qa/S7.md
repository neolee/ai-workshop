## 5. 实施中的小问题

1. **openpyxl 会把空字符串写成空单元格**：登记表里用 `""` 占位的可选字段，保存后读回是 `None`，属于预期行为，不影响阅读。
2. **本地路径应为相对路径**：数据库里存的是绝对路径，导出时统一转成 `data/raw/<source_id>`，便于迁移。
3. **数据更新时间缺失时的回退**：BEA 等来源没有独立发布字段，回退取 HTTP `Last-Modified`。

## 7. 交付后微调（2026-10-20）

- **地均 GDP 单位由「美元/km²」改为「亿美元/km²」**，小数位 0 → 2。原数值量级在 10⁶–10⁹，不易读；
  改后为 0.02–17.71，一屏可读。
- 同时把「单位 / 小数位 / 缩放 / 格式」从 `export.py` 移入 `config/params.yaml` 的 `indicators`，
  导出层从配置读取，避免两处维护。
- **单元格保留全精度，仅由 `number_format` 控制显示**（DD-04）：例如北京 2000 年地均为
  `0.02449675585592167`，显示为 `0.02`，下游取数不丢精度。
- 变更后重跑 `citygdp all --skip-fetch`，49 项测试通过，校验仍为 0 error / 0 warn。
